# 试炼岛卡片投放与自动攻击控制台

用于 Windows 环境下的《穿越火线》试炼岛辅助工具。启动脚本后会打开本地控制台，可在“卡片投放”和“自动攻击”两个页面间切换。

> 本项目仅供学习与交流。请遵守游戏用户协议和相关规则，并自行承担使用自动化工具的风险。

## 功能

### 卡片投放

- 选择 1～6 星卡片、卡片序号和投放数量。
- 通过 `Win + 任务栏序号` 切换至目标程序。
- 自动按 `E`、选择卡片并点击“召唤 Boss”。
- 检测 `damage_ratio.png` 指示的战斗提示；提示消失后会尽快开始下一轮投放。

### 自动攻击

- 先切换至设置的任务栏目标程序，再开始执行。
- 持续按住鼠标左键。
- 每隔 10 秒按一次 `F` 键。

### 通用操作

- 点击控制台右上角的 **停止当前任务**：立即终止当前任务，并松开鼠标左键。
- 修改任意设置后再次点击启动，会自动终止旧任务并按新条件重新开始。
- 可在控制台上传 JPG、PNG 或 WebP 作为背景壁纸，也可恢复默认壁纸。

## 环境要求

- Windows 10/11
- Python 3.10 或更高版本
- 《穿越火线》窗口和界面布局需与脚本坐标相匹配（当前坐标按 1920×1080 设计）
- 目标游戏窗口不要被其他窗口遮挡

## 安装与运行

在项目目录打开 PowerShell，执行：

```powershell
python -m pip install -r requirements.txt
python boss_automation_v2.py
```

脚本会请求管理员权限；请在 Windows 弹窗中允许。成功后，浏览器会自动打开 `card_control_panel.html` 控制台。

## 使用方法

### 1. 确认任务栏位置

控制台中的“任务栏位置”表示从左到右第几个任务栏图标，范围为 1～9。例如游戏位于第 4 个图标时，请填写 `4`。

### 2. 卡片投放

1. 进入“卡片投放”页面。
2. 选择卡片星级、卡片序号、投放数量和游戏任务栏位置。
3. 点击“发送设置并启动”。
4. 需要中止时点击右上角“停止当前任务”。修改设置后再次点击启动即可重置任务。

### 3. 自动攻击

1. 进入“自动攻击”页面。
2. 填写游戏任务栏位置。
3. 点击“启动自动攻击”。
4. 程序切换至游戏后，会按住鼠标左键并每 10 秒按一次 `F`。
5. 需要中止时点击右上角“停止当前任务”。

## 图片识别文件

`damage_ratio.png` 是卡片投放流程的战斗状态识别模板，必须和 `boss_automation_v2.py` 放在同一目录。请不要删除或随意改名该文件。

如果游戏分辨率、界面缩放或 UI 布局发生变化，可能需要重新截取对应区域的图片，否则识别与下一轮投放时机会受到影响。

## 文件夹版 EXE 打包

先安装 PyInstaller：

```powershell
python -m pip install pyinstaller
```

在项目根目录执行：

```powershell
pyinstaller --noconfirm --clean --onedir --windowed --name BossAutomation --add-data "card_control_panel.html;." --add-data "damage_ratio.png;." boss_automation_v2.py
```

打包结果位于：

```text
dist\BossAutomation\
```

请保留整个 `BossAutomation` 文件夹，并运行其中的 `BossAutomation.exe`；不要只单独复制 `.exe` 文件。

## 常见问题

**控制台显示“未连接”**

请先启动 `boss_automation_v2.py` 或打包后的 `BossAutomation.exe`，再点击控制台按钮。

**没有正确切换到游戏**

检查任务栏位置是否正确，并确保对应图标没有被固定项、其他程序或窗口顺序变化影响。

**投卡时机不正确或识别不到战斗结束**

确认游戏为 1920×1080、系统缩放与游戏 UI 布局没有变化，且 `damage_ratio.png` 保持在脚本同目录。
